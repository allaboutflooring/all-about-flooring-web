# Alternate design direction — preserved, not deleted

These files are the "editorial stone" direction (Cormorant Garamond + Jost,
bone/greige/clay palette, video hero) that appeared in the project mid-session.

They were moved here rather than deleted when the token set they depend on
was restored to the graphite/oak system the rest of the site is built in.

Nothing here is imported. To go back to this direction, restore
`tokens.editorial.css` over `src/styles/tokens.css`, restore
`global.before-restore.css`, and copy the components back over
`src/components/`.
